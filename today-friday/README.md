# today-friday

Мини-сервис «Сегодня пятница?» с оплатой 99 ₽.

## Что уже есть
- PHP 7.4+.
- Серверная проверка дня недели.
- API создания платежа и проверки его статуса.
- Webhook endpoint.
- SQLite не требуется: используется MySQL.
- Платёжная архитектура подготовлена для подключения Точки.
- Архитектура кассы подготовлена для подключения «Диджитал Кассы».
- Секреты вынесены в `.env`.
- Ответ «ДА/НЕТ» выдаётся только через серверный API после статуса `paid`.
- Деморежим позволяет проверить интерфейс без реального эквайринга.

## Важно
В ZIP платёжный провайдер работает в режиме `stub`: реальные деньги не списываются.
Для production необходимо подключить актуальные API Точки и «Диджитал Кассы», добавить их ключи в `.env` и реализовать подпись/проверку webhook согласно актуальной документации провайдеров.

## Быстрый запуск

```bash
cp .env.example .env
composer install
php -S localhost:8080 router.php
```

Откройте `http://localhost:8080`.

### Деморежим
В `.env`:

```env
APP_ENV=local
PAYMENT_PROVIDER=stub
STUB_AUTO_PAY=true
```

После нажатия «Узнать правду» тестовый платёж автоматически станет оплаченным.

## MySQL

Создайте БД:

```bash
mysql -u root -p < database/schema.sql
```

Затем укажите параметры подключения в `.env`.

## Production
- `APP_ENV=production`
- `APP_DEBUG=false`
- `STUB_AUTO_PAY=false`
- HTTPS обязателен.
- Настройте web root на каталог `public`.
- Маршруты `/api/*` должны проксироваться на PHP-файлы из `api/` либо используйте приложенный `router.php` только для локальной разработки.
- Не коммитьте `.env`.
